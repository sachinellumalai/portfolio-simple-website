## Personal Portfolio Website

This is a simple personal portfolio website built using **HTML and basic CSS**.
The website contains two pages: **Home** and **Contact**.

* **Home Page:** Displays my introduction, profile, and basic information about me as an aspiring web developer.
* **Contact Page:** Provides a way for visitors to reach out to me.

This project was created to practice fundamental web development skills and to showcase my portfolio as I continue learning **HTML, CSS, and JavaScript**.

### Technologies Used

* HTML
* CSS
